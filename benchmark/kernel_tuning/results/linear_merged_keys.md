# Merged Linear keys

BF16 (64, 4096) is both Qwen3.5-9B `gdn.in_proj_ba` and DeepSeek-V4-Flash
`indexer.weights_proj`. It is one dispatch row (`MERGED_KEYS` in
`linear_smallm_table.py`) and keeps CuTe only where each model's own acceptance
qualifies it. Both sites ran in one call per device (`linear_smallm.py --accept
--l2 cold|engine|hot --shapes <site>.json --m 1,2,3,4,5,8,9,16`, 20 pairs,
cuBLAS with torch default flags; GB10 pinned to the X925 cores). Cells are the
paired speedup over F.linear (ε). Every row is correct and PASS. The gate
re-derives the shipped rows unchanged: RTX 5090 M=2–16, RTX PRO 6000 M=1–16 and
GB10 M=2–8 on the 16/32-row, 128-K, 32-split register variant; other M stay on
cuBLAS. M=17–64 is not tabled for this key (cuBLAS).
